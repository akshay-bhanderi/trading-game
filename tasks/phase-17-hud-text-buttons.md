# Phase 17 — HUD Buttons: Icons → Text Labels

[← Back to index](../TASK.md)

Status: **Complete (T074).**

> Not part of the original design doc's build order — user-directed UI change. The bottom action-button row and the top hamburger menu button in `src/ui/components/Hud.tsx` currently render as icon-only buttons (`BankIcon`, 📰, `BedIcon`, `CompassIcon`, `CoinIcon`, `SkylineIcon`, `HotelIcon`, ✈️, `MenuIcon` — see `PixelIcons.tsx`). The user wants these specific buttons to show their names as small text-label buttons instead of icons. **Scope, per user decision:** only the bottom bar (`.hud-bottom`) and the top menu button (`.hud-menu-btn`) — the top-right wallet chip (coin/cargo icons) and the conditional "Buy hotel here" chip icon are explicitly OUT of scope and stay as-is.
>
> **Resolved (2026-08-01):** all 8 `.hud-bottom` buttons and `.hud-menu-btn` now render their existing `aria-label` string as plain button text (no wrapping span needed — `>Bank<` etc.), no abbreviation used ("Real Estate" kept in full — it wraps to its own row on narrow widths, doesn't clip). `.hud-icon-btn`/`.hud-menu-btn` in `App.css` switched from fixed 48px/32px icon-tile sizing to auto-width text pills (`font-family: var(--font-body)` i.e. VT323, `white-space: nowrap`, small padding); `.hud-icon-glyph` (the emoji-sizing class) was deleted outright since both of its call sites (📰/✈️) were converted to plain text and nothing else referenced it. `BankIcon`, `CompassIcon`, `SkylineIcon`, `BedIcon`, and `MenuIcon` were removed from `PixelIcons.tsx` after grepping the whole repo and confirming each had no other call site; `CoinIcon`/`CargoIcon`/`HotelIcon` were kept since the out-of-scope wallet chip and "Buy hotel here" chip still use them. Verified in-browser (dev server + Chrome automation at a 400×800 window, matching the app's fixed 360px-wide frame): the 8 bottom-bar buttons wrap cleanly to two rows (Bank/Newspaper/Stay/Travel/Market, then Warehouse/Real Estate/Aviation) with no clipping or horizontal overflow, Bank still opens the Bank popup, and Menu still opens the Menu popup with "Menu" as its label.
