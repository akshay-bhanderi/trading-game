    **Important, unexpected finding:** random/greedy shifted by 8–14% at every checkpoint despite NEITHER bot ever touching any Phase 2 code path. Root cause: `eventEngine.ts`'s `scheduleEvent` draws the day's random event type via `rng.pick(PRICE_EVENT_TYPE_IDS)`, and Phase 12 (T065) added `aviationSafetyIncident` to that pool — diluting every OTHER event type's odds from 1-in-11 to 1-in-12, for every game, everywhere, regardless of whether anyone owns a plane. This is a real, structural side effect of Phase 12 landing, predating T067/T068 entirely, surfaced here for the first time because `baseline.v1.json` was generated before Phase 12 existed. Greedy's day-10 miss (1.9% over its 3× — sorry, 0.5×-target cap) traces to this dilution, not to anything T067/T068 changed; retuning the 11 original §7 event probabilities to compensate is a v1-balance (T029-era) concern, explicitly out of this task's `config.ts`-Phase-2-sections-only scope, and the miss is small enough (day-30/90 both comfortably pass) not to warrant reopening that surface now. Documented here rather than silently accepted.

Re-tune — done.** One constant changed, and it's a bot-heuristic, not a §14–16 ⚙ constant: `newsBot.ts`'s `PHASE2_AFFORDABILITY_MULTIPLE` raised **8 → 20** (see that constant's own updated doc comment for the full derivation). At 8×, newsBot's Phase 2 spending pulled day-90 net worth to ~$123k (CI sample) / needed checking at full spec — well under the $200k–400k target — because neither a warehouse's own structure nor a hotel's counts toward `calcNetWorth` (only stored warehouse goods and plane value do, per T048/T064's own explicit rules; confirmed this is NOT a formula gap — a warehouse's OWN structure is equally excluded, so hotel's exclusion is consistent, not an oversight) and a hotel's payback period (cost ÷ daily revenue) runs into the hundreds of days, far past any checkpoint here. 8× let the bot commit to that slow-payback trade far too eagerly relative to how much faster pure trading compounds in the same window. No §14–16 `CONFIG` constants were changed — the systems' own designed economics (build costs, revenue rates, license fees, depreciation) are untouched; only how AGGRESSIVELY one bot chooses to use them changed. Post-retune, `phase2AssetCheckpoints` still shows real, growing exposure (median ~$106,500 at day 90, full spec) — meaningful, not dominant (net worth still tracks the pure-trading target band almost exactly at day 90).
